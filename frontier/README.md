# Frontier monitoring

Monitoring is initially manual. Prefer official release feeds, repositories, specifications and papers; label community signals separately. Do not install or execute discovered repositories automatically. Record primary source, review date, problem, evidence and investigation trigger in [watchlist](watchlist.md).

When activated, weekly reports use `weekly/YYYY-WXX.md` with: strongest signals; releases worth testing; standards/protocol changes; important repositories; important papers; model/inference updates; agent/coding-agent updates; NVIDIA/physical-AI updates; noise deliberately ignored; changes to TECH_RADAR.md; experiments added to backlog. Paper reviews use the shared template. No weekly reports have been produced yet.
