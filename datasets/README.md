# Dataset policy

Allowed by default: public, properly licensed research data, generated synthetic examples and small manually created evaluation fixtures. Public availability alone does not grant redistribution rights.

Do not store employer/confidential material, PII, copyrighted corpora without redistribution permission, access tokens, personal emails/messages or proprietary customer information. Do not commit large datasets or model weights.

Each dataset manifest records source URL, license/redistribution rights, acquisition date, integrity hash, generation method where applicable, transformations, train/evaluation split, leakage controls, storage location and deletion/retention plan. Use documented downloads only after checking licensing. Store large originals outside Git or in ignored datasets/raw/. Commit only approved small sanitized fixtures. No datasets are included yet.
